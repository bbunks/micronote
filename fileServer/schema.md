# fileServer Schema

`/` Root
- Returns Server Info

`/key` Keys
- GET - gets a list of all keys
- POST - requests a new key under a name

`/file` Files



# DataSchema

## File
- id - int
- name - string - generated by server - uuid
- owner - string - declared by uploader
- size - number - found at the time the file is uploaded

## Key
- id - int
- name - string - declared by uploader - unique
- publicKey - generated by server - unique
- privateKey - generated by server
